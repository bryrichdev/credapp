Set up two-step sign-in

Admin accounts must use two-step sign-in. Set it up now to continue; it takes a minute.

After your password, signing in will also ask for a code from your phone.

  1. Install an authenticator app on your phone if you don't have one: Google Authenticator, Microsoft Authenticator, 1Password and Authy all work.
  2. Scan this code with the app.

    Can't scan? Choose "enter a setup key" in the app and type: ABCD EFGH

  3. Enter the 6-digit code the app shows for CredCloud.
